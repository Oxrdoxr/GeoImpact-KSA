# GeoImpact KSA

لوحة قرار تجيب: **هل ينمو القطاع الثالث بتوازن بين مناطق المملكة ومجالات العمل، وكم جهة تحتاجها كل منطقة لتطابق حصتها من السكان؟** مبنية على سجلات منصة نوى.

المؤشر يقارن **التسجيل** بحصة السكان؛ لا يثبت وجود طلب غير ملبّى ولا يقيس جودة الخدمة.

## ما يقدمه المشروع

- **لوحة تفاعلية** (`dashboard/`): فلتر المجال والفئة اللونية، ولوحة «الأكثر حرجًا أولًا»، وخريطة عجز بين المناطق والمجالات، وتفاصيل كل منطقة، وبحث في الكيانات. كل نقرة تحدّث بقية اللوحات.
- **خط تحليل** (`scripts/run_pipeline.py`) من 6 مراحل يولّد كل شيء بالأكواد.
- **تقرير تنفيذي** (`report/`) بصيغ md وhtml وpdf، و**رسوم ثابتة** (`outputs/figures/`) تطابق رسوم اللوحة، وكلاهما يتحدث مع كل تشغيل.

## المنهجية باختصار

1. **الحصة العادلة** = جهات المجال وطنيًا × (سكان المنطقة ÷ إجمالي السكان).
2. **الفجوة** = الحصة العادلة − المسجل فعليًا، وعدد الجهات المطلوبة هو الفجوة مقرّبة وغير سالبة.
3. **نسبة التغطية** = المسجل ÷ الحصة العادلة، وتُصنَّف: عجز حرج (< 0.5)، فجوة متوسطة (< 0.85)، متوازن (≤ 1.25)، تشبع (> 1.25).
4. **نسبة سدّ المنطقة** تحسب كل مجال حتى حدّ حصته فقط، فلا يُخفي فائضٌ عجزًا؛ وبها تُرتَّب المناطق من الأكثر حرجًا.

التفاصيل الكاملة في التقرير التنفيذي `report/executive_summary.md`.

## مصادر البيانات والسياق

- **السكان:** الهيئة العامة للإحصاء، [لوحة معلومات المناطق الإدارية](https://www.stats.gov.sa/ar/w/%D8%B9%D8%B1%D8%B6-%D9%85%D8%B9%D9%84%D9%88%D9%85%D8%A7%D8%AA-%D8%A7%D9%84%D9%85%D9%86%D8%A7%D8%B7%D9%82-%D8%A7%D9%84%D8%A5%D8%AF%D8%A7%D8%B1%D9%8A%D8%A9?category=127436&tab=436327)، ضمن صفحة إحصاءات تعداد السعودية 2022. ملف `data_clean/regional_population_census_2022.csv` يحتفظ بالقيم مقربة إلى 0.1 مليون؛ لم تُستبدل بأعداد أدق قبل التحقق من جدول التنزيل الرسمي.
- **سياق القطاع:** التقرير السنوي 2025 للمركز الوطني لتنمية القطاع غير الربحي، [صفحة التقارير الرسمية](https://ncnp.gov.sa/ar/reports)، ص 18. يذكر أن الإنفاق التنموي بلغ 76.2% من إجمالي إنفاق القطاع في 2024، مقابل 75.3% في 2023، وأن عمليات الفحص والمراجعة تجاوزت 2,300 في 2025. هذه مؤشرات وطنية للسياق فقط؛ لا تدخل في حساب الحصص أو الفجوات، ولا تقيس توزيع جهات نوى أو جودة خدماتها.

## هيكل المشروع

```text
data_clean/                    البيانات المنظفة والتعداد السكاني (الخام والمرحلي غير مرفوعين)
notebooks/cleaning_data.ipynb  تنظيف البيانات وإنتاج المصنف النهائي
scripts/run_pipeline.py        المشغّل
scripts/skills/                ingest · coverage · dashboard_export · figures · report
scripts/data_pulling.py        سحب البيانات الخام من واجهة نوى
outputs/                       ملفات JSON/CSV المحسوبة (يقرؤها الـ dashboard) و figures/
dashboard/                     واجهة بلا منطق تحليلي: العرض والتفاعل فقط
report/                        التقرير التنفيذي
tests/                         اختبارات الوحدة
```

## التشغيل

```powershell
python -m venv venv
.\venv\Scripts\pip install -r requirements.txt

# 1) (اختياري) سحب البيانات الخام ثم تشغيل دفتر التنظيف لإنتاج data_clean/Saudi_Charities_Governance_Final_2026.xlsx

# 2) خط التحليل: يولّد outputs/ و outputs/figures/ و report/
.\venv\Scripts\python scripts\run_pipeline.py

# 3) اللوحة (تحتاج خادمًا محليًا لأنها تستخدم fetch)
.\venv\Scripts\python -m http.server 8765
# ثم افتح http://localhost:8765/dashboard/

# الاختبارات
.\venv\Scripts\python -m pytest -q tests
```

ملف PDF يُنتَج عبر Edge أو Chrome إن وُجد، وإلا يبقى md وhtml فقط.

## الخصوصية والحدود

- الملف الخام `data_clean/nawa_raw_hierarchy.jsonl` والمصنف المرحلي يحويان بيانات أفراد ولا يُرفعان؛ المخرجات تحتفظ بعدد أعضاء المجلس فقط.
- الصناديق العائلية مجال مستقل، وإشرافها مشتق من نوع الكيان ومُوسوم بذلك (`supervisor_source`, `category_source`).
- أرقام السكان مقرّبة إلى 0.1 مليون، لذا قد تتأثر المناطق الأقل سكانًا بالتقريب.
- الجهات غير المصنفة (22) مستبعدة من المقارنة.

سجل استخدام الذكاء الاصطناعي في `ai_usage_log.md`.
